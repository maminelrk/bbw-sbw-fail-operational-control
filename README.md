MATLAB project for fault-aware control allocation across four independent brake effectors and one shared steering rack driven by two independently masked actuator channels. The repository contains implementation, validation code, project-owned technical documentation and the final bilingual reports. The CDC, reference reports, internship workflow, their extracted contents, and generated simulation evidence are intentionally excluded.

Projet MATLAB d'allocation de commande tolérante aux défaillances pour quatre actionneurs de freinage indépendants et une crémaillère commune entraînée par deux canaux d'actionneur masqués indépendamment. Le dépôt contient l'implémentation, le code de validation, la documentation technique propre au projet et les rapports finaux bilingues. Le CDC, les rapports de référence, le workflow de stage, leurs contenus extraits et les preuves de simulation générées sont volontairement exclus.
