# Fail-Operational BbW/SbW Control Allocation

[English](README.en.md) | [Français](README.fr.md)

MATLAB/Simulink project for fault-aware control allocation across four independent brake effectors and one steering effector. The repository contains only implementation, validation, and project-owned technical documentation. The CDC, Gate 1 report, internship workflow, and their extracted contents are intentionally excluded.

Projet MATLAB/Simulink d'allocation de commande tolérante aux défaillances pour quatre actionneurs de freinage indépendants et un actionneur de direction. Le dépôt contient uniquement l'implémentation, la validation et la documentation technique propre au projet. Le CDC, le rapport Gate 1, le workflow de stage et leurs contenus extraits sont volontairement exclus.

Development status / État du développement: **Gate 2 validation baseline / Référence de validation Gate 2**.
