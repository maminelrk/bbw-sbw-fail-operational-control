Sur GitHub, ouvrez le fichier souhaité et utilisez **Download raw file** pour l'enregistrer.

Importez le ZIP dans Overleaf, choisissez pdfLaTeX et sélectionnez `final_report.en.tex` ou `final_report.fr.tex` comme document principal. Modifiez `report.tex` pour le contenu bilingue commun. Toutes les images nécessaires sont incluses. Aucune exécution MATLAB n'est nécessaire. Consultez le README LaTeX pour la compilation locale.

Les PDF finaux et leurs sources LaTeX autonomes sont publiés avec l'autorisation des auteurs. Le CDC, les documents de référence tiers, les rapports historiques et les résultats bruts de simulation restent exclus. Cette publication ne modifie ni les résultats techniques ni les limites de validation.
