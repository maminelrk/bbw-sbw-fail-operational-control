On GitHub, open the desired file and use **Download raw file** to save it.

Upload the ZIP to Overleaf, choose pdfLaTeX and select `final_report.en.tex` or `final_report.fr.tex` as the main document. Edit `report.tex` for the shared bilingual content. All required images are included. No MATLAB run is needed. See the LaTeX README for local compilation instructions.

The final PDFs and their self-contained LaTeX sources are published with the authors' authorization. The CDC, third-party reference documents, historical reports and raw simulation evidence remain excluded. This publication does not change the technical findings or validation boundaries.
